1

git이 이미 있는지 확인

먼저 터미널을 열고 git이 이미 설치돼 있는지 확인해요.

💡 터미널 여는 법: ⌘ + Space → "터미널" 입력 → Enter
jinny — bash
%git --version
✓ 결과 A
git version 2.x.x 가 나오면
이미 설치됨 → STEP 3으로 이동
✗ 결과 B
command not found 오류 → STEP 2로 이동
2

git 설치

OPTIONAL · git 없을 때만

macOS는 아래 명령어 한 줄로 git을 설치할 수 있어요.

jinny — bash
%xcode-select --install
📦 설치 창이 팝업으로 뜨면 [설치] 버튼 클릭 → 5~10분 대기

설치 후 다시 확인:

jinny — bash
%git --version
git version 2.39.5
↑ 이렇게 버전이 나오면 성공 🎉
3

git에 내 이름 / 이메일 등록

git은 코드를 저장할 때 "누가 저장했는지" 기록을 남겨요. 그래서 미리 본인 이름과 이메일을 등록해둬야 해요.

jinny — bash
%git config --global user.name "홍길동"
%git config --global user.email "hong@email.com"
✏️ 따옴표 안의 내용만 본인 이름/이메일로 바꾸세요.
아무 반응 없이 다음 줄로 넘어가면 성공이에요.

확인하고 싶다면:

jinny — bash
%git config --global user.name
홍길동
%git config --global user.email
hong@email.com

Node.js 설치

OPTIONAL · npm 없을 때만

Node.js를 설치하면 npm도 함께 설치돼요.

1
nodejs.org 접속 → LTS 버전 다운로드 클릭
2
다운받은 파일 열어서 설치 (계속 → 계속 → 설치)
3
터미널을 완전히 종료하고 다시 열기 ← 꼭 해야 해요!
4
설치 확인 (아래 명령어 실행)
jinny — bash
%node --version
v20.11.1
%npm --version
10.2.4
↑ 둘 다 나오면 성공 🎉
6

Claude Code 설치

npm이 준비됐으면 Claude Code를 설치해요.

jinny — bash
%npm install -g @anthropic-ai/claude-code
⠋ 설치 중... 잠깐 기다려요
%claude --version
claude v1.0.x
↑ 버전이 나오면 성공 🎉
⚠️ 설치 중에 경고 메시지가 나와도 마지막에 버전이 출력되면 정상이에요.
7

첫 실행 & 인증

설치 후 처음 한 번 실행해서 Anthropic 계정 인증을 해야 해요.

jinny — bash
%claude
↑ 브라우저가 자동으로 열려요
1
브라우저에서 Anthropic 계정 로그인 화면이 뜨면 로그인
2
인증 완료 메시지가 나오면 터미널로 돌아오기
3
종료는 Ctrl + C 또는 /exit
💡 Claude Desktop 앱의 Code 모드를 한 번 열어도 인증이 돼요.
8

CLI 실습

터미널 기본 명령어를 연습해봐요. 아래 명령어를 한 줄씩 입력하고 Enter를 눌러보세요.

📍 어디에 입력하나요?
지금까지 했던 것처럼 일반 터미널에 입력하면 돼요.
jinny — bash
%mkdir cli-practice# 폴더 생성
↳ 아무 반응 없으면 정상
%cd cli-practice# 폴더 안으로 이동
↳ 프롬프트가 cli-practice % 로 바뀜
%pwd# 현재 위치 확인
/Users/jinny/cli-practice
%ls# 폴더 내용 보기
↳ 빈 폴더라 아무것도 안 나와도 정상
%git init# git 저장소 초기화
Initialized empty Git repository in /Users/jinny/cli-practice/.git/
%ls -a# 숨김 파일 포함 보기
.  ..  .git
↳ .git 이 보이면 성공 🎉
🔍 .git은 git이 변경 이력을 저장하는 숨김 폴더예요. ls만 했을 땐 안 보이고, ls -a를 해야 보여요.
9

저장소 직접 만들기

미리 만들어진 저장소를 받지 않고 본인 손으로 빈 작업 폴더를 만들어요.
각 파일의 역할을 직접 이해하는 게 자산화의 첫걸음이에요.

📍 어디에 입력하나요?
지금까지 했던 것처럼 일반 터미널에 입력하면 돼요. 아래 명령어를 한 줄씩 입력하고 Enter를 누르세요.

Step 1. 빈 작업 폴더 생성

jinny — bash
%mkdir wit-claude-intermediate# 폴더 생성
↳ 아무 반응 없으면 정상, 다음 줄 입력
%cd wit-claude-intermediate# 폴더 안으로 이동
↳ 프롬프트가 wit-claude-intermediate % 로 바뀜
%git init# git 저장소 초기화
Initialized empty Git repository in /Users/jinny/wit-claude-intermediate/.git/

Step 2. Claude Code 실행

방금 만든 폴더 안에서 그대로 아래 명령어를 입력해요.

jinny — wit-claude-intermediate
%claude
↳ 현재 폴더에서 Claude Code가 실행돼요
💡 또는 Claude Desktop의 Code 모드에서 이 폴더를 열어도 돼요.
