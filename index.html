CLI란?

CLI(Command Line Interface)는 마우스 클릭 대신 키보드로 명령어를 입력해서 컴퓨터를 조작하는 방식이에요.
우리가 매일 쓰는 폴더, 파일, 프로그램 실행 같은 작업을 텍스트 명령어로 처리해요. 개발자들이 더 빠르고 정확하게 작업하기 위해 사용하는 도구예요.

예시 mkdir folder → "folder" 폴더 만들기
예시 cd folder → "folder"로 이동
예시 git init → git 저장소 시작
git이란?

git은 코드의 변경 이력을 기록·관리하는 도구예요. "언제, 누가, 무엇을 바꿨는지" 모두 추적할 수 있어서, 실수해도 이전 상태로 되돌릴 수 있어요.
여러 명이 협업할 때도 각자의 작업을 한 곳에 합칠 수 있게 도와줘요. 개발자들이 가장 많이 쓰는 협업 도구예요.

이 가이드에서 "git 설치"는 이 도구를 컴퓨터에 깔아두는 작업이에요. 한 번만 설치하면 계속 쓸 수 있어요.

git에 내 이름 / 이메일 등록

git은 코드를 저장할 때 "누가 저장했는지" 기록을 남겨요. 그래서 미리 본인 이름과 이메일을 등록해둬야 해요.

jinny — bash
%git config --global user.name "홍길동"
%git config --global user.email "hong@email.com"
✏️ 따옴표 안의 내용만 본인 이름/이메일로 바꾸세요.
아무 반응 없이 다음 줄로 넘어가면 성공이에요.

확인하고 싶다면:

jinny — bash
%git config --global user.name
홍길동
%git config --global user.email
hong@email.com

Claude Code 설치

npm이 준비됐으면 Claude Code를 설치해요.

jinny — bash
%npm install -g @anthropic-ai/claude-code
⠋ 설치 중... 잠깐 기다려요
%claude --version
claude v1.0.x
↑ 버전이 나오면 성공 🎉
⚠️ 설치 중에 경고 메시지가 나와도 마지막에 버전이 출력되면 정상이에요.

권한 에러가 나는 경우

설치 중에 다음과 같은 EACCES 권한 에러가 나는 경우가 있어요:

jinny — bash
npm error code: 'EACCES',
npm error syscall: 'mkdir',
npm error path: '/usr/local/lib/node_modules/@anthropic-ai'
npm error The operation was rejected by your operating system.
npm error It is likely you do not have the permissions to access...

이 에러는 전역 설치 권한이 없어서 발생해요. 명령어 앞에 sudo를 붙여서 다시 실행하세요:

jinny — bash
%sudo npm install -g @anthropic-ai/claude-code
↳ 비밀번호를 물어보면 Mac 로그인 비밀번호 입력 (입력해도 화면에 안 보여요, 정상)
%claude --version
claude v1.0.x
↑ 버전이 나오면 성공 🎉
💡 sudo가 뭔가요?
"관리자 권한으로 실행"이라는 뜻이에요. Mac이 시스템 폴더에 뭔가 설치하려면 본인이 진짜 사용자인지 확인하려고 비밀번호를 물어봐요.

비밀번호 입력 시 화면에 점(●)이나 별표(*)도 안 보이지만 정상이에요. 그냥 입력하고 Enter 누르세요.

첫 실행 & 인증

설치 후 처음 한 번 실행해서 Anthropic 계정 인증을 해야 해요.

jinny — bash
%claude
↑ 브라우저가 자동으로 열려요
1
모드 선택 화면이 먼저 나와요. 화살표 키로 모드를 고르고 Enter
2
그 다음 인증 방법 선택 화면이 나오면 Anthropic 계정 로그인 선택
3
브라우저가 자동으로 열리면서 Anthropic 계정 로그인 화면이 뜨면 로그인
4
인증 완료 메시지가 나오면 터미널로 돌아오기
5

⚠️ 모드 선택을 먼저 해야 브라우저 계정 연결 화면으로 넘어가요. 모드 선택 없이 멈춰있다면 그 단계가 안 넘어간 거예요.
💡 Claude Desktop 앱의 Code 모드를 한 번 열어도 인증이 돼요.

저장소 직접 만들기

미리 만들어진 저장소를 받지 않고 본인 손으로 빈 작업 폴더를 만들어요.
각 파일의 역할을 직접 이해하는 게 자산화의 첫걸음이에요.

📍 어디에 입력하나요?
지금까지 했던 것처럼 일반 터미널에 입력하면 돼요. 아래 명령어를 한 줄씩 입력하고 Enter를 누르세요.

Step 1. 빈 작업 폴더 생성

jinny — bash
%mkdir wit-claude-intermediate# 폴더 생성
↳ 아무 반응 없으면 정상, 다음 줄 입력
%cd wit-claude-intermediate# 폴더 안으로 이동
↳ 프롬프트가 wit-claude-intermediate % 로 바뀜
%git init# git 저장소 초기화
Initialized empty Git repository in /Users/jinny/wit-claude-intermediate/.git/

Step 2. Claude Code 실행

방금 만든 폴더 안에서 그대로 아래 명령어를 입력해요.

jinny — wit-claude-intermediate
%claude
↳ 현재 폴더에서 Claude Code가 실행돼요
💡 또는 Claude Desktop의 Code 모드에서 이 폴더를 열어도 돼요.
